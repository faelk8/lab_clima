# Post 1/5 — De onde vêm os dados do clima?

Fase vinculada: Fase 1. Status: RASCUNHO. Capa: “Dado climático é fácil de baixar. Difícil é explicar sua origem.” Artefato: diagrama de proveniência das três localidades. Métricas: uma consulta de um dia à API para São Paulo respondeu HTTP 200 e retornou 1.026 bytes; evidência `docs/evidence/F1-08.md`.

No ClimateWatch, comecei pelo contrato e pela origem dos dados. Consultei a API histórica da Open-Meteo, verifiquei coordenadas e fusos de São Paulo, Recife e Manaus e registrei a atribuição exigida. A fonte histórica usa produtos de modelo e reanálise; não vou chamar esses valores de observações de estação.

Preparei um coletor com timeout e um armazenamento raw que preserva a resposta original e seu hash. Assim, a transformação pode ser refeita a partir do mesmo payload. O teste offline usa fixtures sintéticas, e a consulta real foi pequena e identificada.

Este laboratório explora dados. Não é alerta oficial nem previsão de enchentes.
